03 / SEARCH ALGORITHM

Depth Limited Search

DLS is an uninformed depth-first search strategy that restricts exploration to a user-defined depth limit.

Description

Depth Limited Search (DLS) is a variation of Depth First Search in which the search is allowed to explore nodes only up to a specified depth limit. In this project, DLS is applied to the 8-Puzzle state-space problem.

Working Principle

01

Start from the initial puzzle state.

02

Check whether the current state is the goal.

03

Generate all valid successor states.

04

Explore successors recursively in depth-first order.

05

Stop expanding a node when the depth limit is reached.

06

Backtrack and explore another branch when required.

07

Return the solution when the goal state is reached.

SEARCH TYPE Uninformed Search
STRATEGY Depth-First
DEPTH CONTROL User Defined
TIME COMPLEXITY O(bl)
SPACE COMPLEXITY O(b·l)
COMPLETE Only up to depth limit
OPTIMAL No
APPLICATION 8-Puzzle

Advantages

  • Uses significantly less memory than breadth-first search.
  • Prevents the search from going beyond the selected depth.
  • Simple recursive implementation.
  • Useful when the expected solution depth is known or bounded.

Limitations

  • May fail when the solution is deeper than the selected limit.
  • Does not guarantee the shortest solution.
  • Performance depends strongly on the selected depth limit.
  • May explore many branches before finding a solution.
Notation: b = branching factor and l = depth limit.

For the 8-Puzzle, each state can generate up to four legal moves depending on the blank-tile position. The implementation also avoids revisiting a state already present on the current search path.
